# Eventos Aventura

Event pages for trail running races.

## Pages

- [`chacay33k/`](chacay33k/) — Chacay 33K route on an interactive 3D relief model (three.js + AWS Terrain Tiles), built from the race GPX.

Open `chacay33k/index.html` in a browser, or serve the folder locally:

```sh
cd chacay33k && python3 -m http.server
```
